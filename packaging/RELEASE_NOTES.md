Download the ZIP matching your computer, extract it, and follow the included
`README.md`. Python and Pygame are bundled.

- **Windows x64:** open `Unsettled/Unsettled.exe` after extracting the whole ZIP.
- **macOS Apple Silicon:** drag `Unsettled.app` into Applications.
- **Linux:** run from source using the repository README.

**No publisher signing yet:** Windows builds are unsigned and may trigger
SmartScreen or antivirus warnings. macOS builds are ad hoc signed only, with no
Developer ID signature or Apple notarization, so Gatekeeper may block the first
launch. See the [download instructions](https://github.com/hjlarrea/unsettled/blob/main/packaging/DOWNLOAD_README.md)
for the expected warnings and available per-app exceptions. Managed computers
may prohibit running these builds.

`SHA256SUMS.txt` contains the SHA-256 checksums of the downloads. Updates are
manual: replace the whole application; saves remain outside the app.
